# ⚛️ Quantum-Inspired Multi-Modal Fusion for High-Dimensional Data

## 🚀 Overview

This project implements a **hybrid quantum-inspired deep learning model** that combines:

* Neural feature compression
* Quantum-inspired encoding
* Transformer-based interaction modeling
* Gated multi-modal fusion

The goal is to explore how **quantum-inspired representations** can improve learning from high-dimensional structured data.

---

## 🧠 Key Idea

```
High-dimensional input
        ↓
Learned compression (MLP)
        ↓
Quantum-inspired encoding
        ↓
Multi-branch representations
        ↓
Transformer-based fusion
        ↓
Prediction
```

---

## 🔬 Features

* ⚛️ Quantum-inspired feature encoding
* 🔗 Transformer-based cross-modal fusion
* 🎚️ Adaptive gating mechanism
* 📊 Robust evaluation with cross-validation
* 🔍 Explainability (feature importance + SHAP)
* ⚖️ Comparison with classical baselines

## 📊 Results

| Model         | Accuracy | F1 Score | AUC      |
| ------------- | -------- | -------- | -------- |
| Quantum Model | 0.63     | 0.62     | 0.89     |
| Random Forest | **0.72** | **0.72** | **0.92** |

---

## 🧠 Key Insights

* Quantum-inspired models are **competitive with deep learning approaches**
* Classical models still outperform on **small tabular datasets**
* Feature compression is a critical bottleneck
* Multi-modal fusion improves representation learning
